## ✨ Features

* **🎨 Japanese Sakura Theme:** A luxurious, glassmorphism-inspired UI with a calm pink shade palette and animated falling cherry blossoms.
* **🖱️ Interactive Petal Burst:** Custom mouse-click animations where cherry blossom leaves scatter from the cursor location.
* **🌿 Smooth Pixel Upscaling:** Advanced client-side canvas smoothing and multi-pass blending to eliminate harsh pixelation and blur out jagged edges.
* **🌑 Deep Contrast & Shadows:** Smart tonal adjustment that deepens black areas for rich depth without crushing details.
* **⚖️ Before/After Comparison Slider:** An interactive split-screen slider to inspect the original and enhanced image side-by-side in real-time.
* **🌸 Color Enhancer:** Lifts vibrancy and balances tones naturally.

---

## 🛠️ Built With

* **HTML5** – Markup structure
* **CSS3** – Styling, custom variables, and glassmorphism effects
* **JavaScript (Vanilla)** – Core upscaling logic, smoothing filters, and DOM manipulation
* **Canvas API** – High-performance image processing directly in the browser
